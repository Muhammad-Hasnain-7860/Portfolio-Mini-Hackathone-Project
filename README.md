# Creative Portfolio

A personal portfolio built to explore the intersection of design, motion, and interactive web experiences.

From scroll-driven SVG animations to immersive 3D project transitions, every section is designed to make the experience feel smooth, expressive, and unique.

##  Highlights

Hero Section — A clean and minimal introduction with elegant typography and a modern layout.

About Section — Features a smooth blur-to-reveal text animation that gradually brings the content into focus as you scroll.

Projects Section — A creative scroll-driven experience featuring animated SVG elements that move along with the page and complete their animation as the section ends.

Gallery Section — A dynamic visual gallery where images appear one by one, move across the screen, and transition smoothly with scrolling.

Skills Section — A minimal and well-organized presentation of my technical skills, keeping the design clean and easy to explore.

Selected Work — An interactive 3D project showcase where each scroll triggers a 3D movement and transitions to the next project, displaying its details through an engaging layout.

Info Section — A simple section providing additional information about me and my work.

Contact Section — A clean and straightforward way for visitors to connect with me.

##  Built With

HTML5 · CSS3 · JavaScript · GSAP · SVG · Lenis
